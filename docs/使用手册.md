## 1. 安装与首次启动

### 1.1 下载

拿到 `pet-4.3.apk`（约 55.6 MB）。建议先核对 MD5：

```
9ed0b37c42c1a09d7ae898db149795c7
```

对不上就重新下载，不要装来路不明的二次打包版本。

### 1.2 安装

1. 用文件管理器点开 APK；
2. 首次会提示「允许安装未知应用」，去设置里给文件管理器或浏览器打开这个开关；
3. 安装完成后，桌面会出现「桌宠」图标。

### 1.3 首次启动

打开 App，你会看到主界面。按顺序做三件事：

1. **授予悬浮窗权限**：点按钮 → 跳到系统设置 → 允许「显示在其他应用上层」→ 返回；
2. **允许通知**（Android 13+）：首次启动会弹窗，点允许；不想看通知可以之后设成静默；
3. **启动桌宠**：点「启动桌宠」，App 会自己关掉并回到桌面。

回到桌面后，宠物应该已经出现在左上偏中的位置。如果没出现，看第 10 节「宠物不显示」。

### 1.4 MIUI / HyperOS 额外设置

小米/红米用户必须多做一步，否则双击宠物打不开 DSHA：

设置 → 应用设置 → 应用管理 → 桌宠 → 权限管理 → **允许「后台弹出界面」**。

顺手把「省电策略」改成「无限制」，「自启动」打开，悬浮窗就不容易被系统回收。

## 2. 主界面说明

主界面从上到下分五块：

### 2.1 头像卡

圆形头像 + 名字「蓝毛小女仆」+ 一行小字「桌面陪伴 · 不需要 root」。

### 2.2 运行状态卡

三行，每行左边是项目名，右边是状态：

| 行 | 绿色（正常） | 橙色（要注意） |
| --- | --- | --- |
| 悬浮窗权限 | 已授予 | 未授予 |
| DSH 连接 | OK 服务正常 | HTTP 错误 / 连接失败 |
| DSHA 客户端 | 已安装 | 未安装 |

三项全绿，说明悬浮窗、服务端、客户端都齐了。

- **DSH 连接**是实时测试 `http://127.0.0.1:38859/dsh-pet-7340/state` 的结果，每 2 秒刷新一次；
- **DSHA 客户端**只是检查有没有装 `dsh.android.client` 这个包，不代表 DSH 服务真的在跑。

### 2.3 按钮区

| 按钮 | 作用 |
| --- | --- |
| 启动桌宠（渐变主按钮） | 启动前台服务，显示悬浮窗，然后退出 App |
| 停止桌宠 | 关闭悬浮窗和前台服务 |
| 授予悬浮窗权限 | 跳系统设置 |
| 测试 DSH 连接 | 立刻测一次连接，结果显示在下面 |

### 2.4 玩法卡

四行手势提示：单击 Q 弹、双击打开 DSHA、长按菜单、拖动换位置。

### 2.5 页脚

版本号 + 「常驻不耗电 · 不依赖 ADB / Shizuku」。

> 如果没装 DSHA，按钮区下面会多出一个「去 GitHub 获取 DSHA」按钮，点它打开下载页。

## 3. 手势操作

所有判定都以「按下点」为起点：

| 操作 | 判定条件 | 结果 |
| --- | --- | --- |
| 单击 | 按住 < 500ms、总位移 < 12dp | Q 弹 + 随机换动作，好感 +1 |
| 双击 | 两次点击间隔 < 400ms、位移 < 80dp | 打开 DSHA |
| 长按 | 按住 ≥ 500ms 且位移 < 12dp | Q 弹 + 震动 28ms + 弹菜单 |
| 拖动 | 位移 > 12dp | 窗口跟手移动 |
| 甩飞 | 松手时拖动距离 > 24dp 且速度 > 1400px/s | 按速度飞出去 |
| 接住 | 宠物飞行中按下 | 停下、好感 +2、气泡「接住啦～」 |

几个细节：

- **拖动有 12dp 死区**：手指轻微抖动不会让宠物乱跑；
- **甩飞有门槛**：必须真的「拖出去再甩」，单纯点一下不会触发；
- **飞行中点击 = 接住**，不会再 Q 弹；
- **动画静默**：拖动、甩飞、点击期间，动画会冻结，只做物理运动；动作播完约 1.2 秒后恢复随机待机。

### 物理参数

| 参数 | 值 |
| --- | --- |
| 反弹系数 | 0.95（撞墙只反弹，不加速） |
| 线性减速 | 480 px/s² |
| 停止阈值 | 40 px/s |
| 甩出初速上限 | 2200 px/s |
| 位置精度 | 浮点锚点，换动作不累积误差 |

## 4. 长按菜单

长按 0.5 秒，宠物先 Q 弹一下、震一下，然后在它旁边弹出一张圆角小卡片。

- 卡片贴在宠物右侧，右边放不下会翻到左侧；
- 12 秒没操作自动关；
- 点卡片外面也关；
- 不是系统对话框，不会挡整个屏幕。

菜单项随「有没有装 DSHA」变化：

| 菜单项 | 装了 DSHA | 没装 DSHA | 说明 |
| --- | --- | --- | --- |
| 打开 DSH | ✓ | — | 启动 DSHA 客户端 |
| 查看余额 | ✓ | — | 刷新并显示余额 |
| 碎碎念 | ✓ | — | 让宠物说一句 |
| 对话 | ✓ | — | 提示去 DSH 聊，并打开 DSHA |
| 获取 DSHA ↓ | — | ✓ | 打开下载页 |
| 动作 ▸ | ✓ | ✓ | 106 个动画，分两级 |
| 大小 ▸ | ✓ | ✓ | 50%–200% 滑块 |
| 显示位置 ▸ | ✓ | ✓ | 仅网页 / 仅桌面 / 两者 / 都不 |
| 回到初始位置 | ✓ | ✓ | 回到第一次出现的位置 |
| 好感度 | ✓ | ✓ | 显示等级和点数 |
| 退出桌宠 | ✓ | ✓ | 关掉悬浮窗和前台服务 |

## 5. 大小调节

菜单 →「大小 ▸」：

1. 弹出深色卡片，中间一条滑块，范围 50%–200%；
2. 拖动时宠物实时缩放，不用确认；
3. 松手自动保存，下次启动还是这个大小；
4. 「重置 100%」回到默认；
5. 「完成」关闭卡片。

注意：只缩放宠物本体，气泡、菜单、文字不跟着缩放，避免字太大挡桌面。

## 6. 动作与显示位置

### 6.1 动作

菜单 →「动作 ▸」进入分类列表，点分类再点具体动画。共 106 个，包括：

- 待机、转向、拖拽、点击回应；
- 移动、小动作、玩耍、吃什么；
- 时节、文字类动作；
- 工作状态（思考冒泡、忙碌点按、等待张望、雀跃庆祝、垂头叹气）；
- 余额、碎碎念相关动作。

选完立刻播放，播完回到随机待机。

### 6.2 显示位置

对应 DSH 网页端右键菜单里的「显示位置」：

| 选项 | 效果 |
| --- | --- |
| 仅网页（web） | 只在浏览器里显示 |
| 仅桌面（desktop） | 只在悬浮窗显示 |
| 两者（both） | 两边都显示（推荐） |
| 都不（none） | 都隐藏 |

碎碎念要求显示模式是 `web` 或 `both`，否则服务端会返回 `pet-not-displayed`。

## 7. 和 DSH 的联动

> 这一节的功能都需要 DSHA（在手机上跑 DSH 的客户端）。没有 DSHA 时，App 会自动隐藏这几项。

### 7.1 工作状态

App 每 2 秒请求一次 `/dsh-pet-7340/state`，读取 `sections.workStatus.data.state`：

| 状态 | 宠物表现 |
| --- | --- |
| `thinking` | 思考冒泡，气泡「让我想想…」 |
| `working` | 忙碌点按，气泡「正在干活…」 |
| `waiting` | 原地踱步张望，「在等你确认哦」 |
| `success` | 雀跃庆祝，「搞定啦！」 |
| `error` | 垂头叹气冒汗，「出错了…」 |

状态变化时才播，不会一直循环打断你。

### 7.2 余额

点「查看余额」后：

1. 先弹「查一下余额…」；
2. `POST /dsh-pet-7340/balance` 让服务端刷新；
3. 等 1 秒；
4. `GET /state` 读 `wallets[0].total`；
5. 气泡显示 `余额 ¥x.xx`。

为什么不直接读 `/state`？因为里面的余额是服务端缓存，可能几分钟不更新，直接读会显示旧数字。

### 7.3 碎碎念

点「碎碎念」后：

1. 先弹「让我想想…」；
2. `POST /dsh-pet-7340/whisper?pet=main&surface=web`；
3. 成功返回 `{"ok":true,"text":"…"}`，气泡显示 `text` 7 秒；
4. 如果返回 `pet-not-displayed`（显示模式被 DSH 重启改回 desktop），App 自动 `POST /pet-display` 改回 `both` 再试一次；
5. 还失败就用内置的 8 句文案兜底。

### 7.4 碎碎念推送

网页端或别的地方产生的 `pets.main.say`，轮询会读到：counter 变了、文本和上次不同，就弹 7 秒气泡。刚启动时只记录 counter，不会把旧消息翻出来。

## 8. 权限与系统适配

### 8.1 权限清单

| 权限 | 用途 | 必须 |
| --- | --- | --- |
| 显示在其他应用上层 | 悬浮窗、气泡、菜单 | 是 |
| 通知 | 前台服务通知 | 建议 |
| 前台服务 / 特殊用途前台服务 | 保活 | 是 |
| 网络 | 访问 `127.0.0.1:38859` | 是 |
| 振动 | 长按、接住、撞墙反馈 | 否 |

### 8.2 各系统开悬浮窗的位置

- 原生 Android：设置 → 应用 → 特殊应用权限 → 显示在其他应用上层；
- MIUI / HyperOS：设置 → 应用设置 → 应用管理 → 桌宠 → 权限管理 → 显示在其他应用上层；
- 三星 One UI：设置 → 应用程序 → 桌宠 → 权限 → 显示在其他应用上层；
- ColorOS / OriginOS：应用管理 → 桌宠 → 权限管理 → 悬浮窗；
- 鸿蒙：设置 → 应用 → 桌宠 → 权限 → 悬浮窗。

## 9. 省电与保活

悬浮窗被系统杀掉是最常见的问题，按下面做基本能稳住：

1. **省电策略**：设置 → 应用 → 桌宠 → 省电策略 → 无限制；
2. **自启动**：允许自启动 / 关联启动；
3. **最近任务加锁**：在多任务界面给桌宠加锁；
4. **通知常驻**：别把前台服务通知关掉，它是保活的关键；
5. **电池优化白名单**：设置 → 电池 → 电池优化 → 桌宠 → 不优化。

耗电方面：待机时只有 2 秒一次的本地 HTTP 请求 + 视频播放，通常 CPU < 2%；飞行和拖动时才按屏幕刷新率绘制。

## 10. 故障排查

### 10.1 宠物不显示

**表现**：启动后桌面没有宠物。

1. 看主界面第一行「悬浮窗权限」是不是「已授予」；
2. 没授予就点按钮去开；
3. 已授予但仍不显示：去最近任务看看 App 是不是被杀了，重新点「启动桌宠」；
4. 检查是不是点到了「停止桌宠」。

### 10.2 状态 / 余额 / 碎碎念没有

**表现**：菜单里没有这几项，或者点了提示连接失败。

1. 没装 DSHA：主界面第三行是「未安装」，菜单里不会出现这几项，属正常；
2. 装了但服务没起：主界面第二行橙色，打开 DSHA 看服务是否启动、端口是不是 38859；
3. 端口不是 38859：本版本写死 38859，需要把 DSH 改到该端口，或在后续版本支持自定义。

### 10.3 双击打不开 DSHA

**表现**：双击没反应。

- MIUI / HyperOS：权限管理里允许「后台弹出界面」；
- 其他系统：确认 DSHA 还装着，且没被卸载或冻结。

### 10.4 碎碎念提示 pet-not-displayed

**原因**：DSH 重启后，宠物显示模式回到了 `desktop`，而 `surface=web` 不满足。

**处理**：App 会自动改回 `both` 并重试；如果还不行，去 DSH 网页端右键宠物 → 显示位置 → 两者。

### 10.5 点击会飘 / 被甩出去

- 4.1 起位置用浮点锚点，换动作不再累积误差；
- 4.3 起甩飞需要拖动 > 24dp 且速度 > 1400px/s，点击不会误触发；
- 如果仍偶尔飘一下，多半是动画本身有位移，不是窗口在动。

### 10.6 黑底 / 动画不动

**原因**：WebView 太旧，不支持 VP9 alpha 或 Canvas 合成。

**处理**：应用商店更新「Android System WebView」或 Chrome，重启桌宠。

### 10.7 第一次播某个动作卡一下

正常现象：106 个视频是按需解码的，第一次播有几十毫秒延迟，之后走缓存就顺了。

### 10.8 悬浮窗过一会消失

看第 9 节，通常是省电策略或后台清理。

## 11. 日志与反馈

诊断日志在：

```
/sdcard/Android/data/com.dsha.pet/files/poll.log
```

用文件管理器或电脑 ADB 都能看。里面每条记录长这样：

```
10-30 13:20:01 POLL GET http://127.0.0.1:38859/dsh-pet-7340/state -> 200 {"counter":...
10-30 13:20:03 POST http://127.0.0.1:38859/dsh-pet-7340/whisper?pet=main&surface=web -> 200 {"ok":true,...
```

出问题时把最近几十行发出来，基本能定位是「服务没起」「端口不对」还是「显示模式不对」。

日志超过 200KB 会自动清空重写，不会一直涨。

## 12. 卸载与数据清理

- 菜单 →「退出桌宠」：只关悬浮窗和前台服务，App 还在；
- 系统设置 → 应用 → 桌宠 → 卸载：全部清掉，包括好感度和大小设置；
- 想保留 App 只清数据：设置 → 应用 → 桌宠 → 存储 → 清除数据（好感度会归零）。
